## Reading it

- **The six missed breaks are label errors.** Both tools miss the same six uses: gradio 4 code run on 3.40.1
  (`Button.click`, `UploadButton.upload`, `Video.stop_recording` on an instance). gradio 3 sets each listener on the
  instance in an event mixin's `__init__` (`self.click = EventListenerMethod(self, "click")`,
  [events.py](https://github.com/gradio-app/gradio/blob/v3.40.1/gradio/events.py#L187-L189)), so the code works and
  DepTime's `present` is right; the probe reads the class and can't see it, the blind spot `../README.md` already names
  for instance attributes. They are now in `label-overrides.json` (found after scoring; not pre-registered). With them
  excluded, both tools' recall is 100% (140/140) and nothing else changes; `baseline.json` uses the corrected labels.
- `check_symbols`'s 38 false positives have five causes, the first new and serious: mcp 2.x's `mcp.types` is a star
  import of the separate `mcp-types` distribution, which isn't indexed, so `mcp.types.Tool`, `TextContent` and the rest
  read missing in 2.x (16), and `diff_versions` on any 1.x → 2.x upgrade reports them removed in 2.0.0. The others are
  langchain-community loaders whose `BaseLoader` comes through the package's own re-export of langchain-core's class
  (10; DT-DATA-55 already describes it), crewai 0.41's pydantic v1-style `__init__(__pydantic_self__, **data)`, whose
  first parameter DT-CORE-34's `missing_args` treats as an argument the call must pass (5), module dunders
  (`mcp.__name__`, `polars.__version__`) and pydantic's generated `__pydantic_serializer__` (6), and transformers 5
  still serving `Qwen2TokenizerFast` (1).
- `diff_versions`'s 5 false positives: the same langchain loader (2), `Qwen2TokenizerFast`, typer 0.19's
  `typer.testing.Result` (imported from click then; DepTime reads it as added when typer defined its own), and
  `StateGraph(State)`, where the pre-registered rule counts a newly required parameter the call passes positionally
  (as on 2026-11).
- **Deprecations** (the stricter truth of this set: evidence about the name itself) mark 14 working uses.
  `check_symbols` flags 17 deprecated, 12 of them among those 14 (recall 85.7%; 60.1–96.0); `diff_versions` flags 16,
  11 of them (78.6%).
- Tracebacks: the three misses are one of each. openai's bare `TypeError: create() got an unexpected keyword argument
  'file_ids'` (no frames, openai 1.28.1 installed) gets a finding for litellm, which isn't installed. scikit-learn's
